## 1. 背景与目标

### 1.1 背景

安卓平台缺少一款**专注于本地小说文件、完全无广告**的阅读器。现有产品要么以在线书城为核心、广告与推广泛滥；要么功能臃肿、学习成本高；要么已停止维护。用户手中大量 TXT / EPUB 格式的小说文件（网文、公版书、自整理文档）缺少一个干净、可靠的管理与阅读工具。

同时，"看累了想听"是高频诉求，但市面产品的听书功能要么依赖在线服务，要么听书进度与阅读进度互相割裂——听完一段再打开书，找不到刚才听到哪了。

### 1.2 产品原则（硬性约束，不可妥协）

| 编号 | 原则 | 说明 |
|------|------|------|
| **P-1** | **完全无广告** | 无开屏/信息流/激励视频等任何形式的广告、无推广位、无诱导内购 |
| **P-2** | **全离线运行** | 不依赖 Google 服务框架（GMS）、不调用任何 Google API 或云服务接口、不集成任何第三方在线服务；默认构建变体**不声明 `INTERNET` 权限**，飞行模式下全部功能可用 |
| **P-3** | **本地优先** | 书库、进度、设置全部保存在本机；无账号体系、零数据收集、无埋点/统计 SDK |
| **P-4** | **不做爬虫** | 不提供在线书城、书源订阅、小说爬取等任何联网内容获取功能（novelmgt 的 `crawler_service` / `book_source` 明确不移植） |
| **P-5** | **开源可分发** | 全部依赖为 AOSP / 开源库，可在 GitHub Release / F-Droid 分发，不绑定 Google Play |

> **"无 Google"的边界定义**：禁止的是 *Google 服务与在线接口*——GMS（Google Play Services）、Firebase、ML Kit、googleapis 系列 REST 接口、Google TTS 引擎依赖、Google Fonts 在线字体等。
> 允许的是 *AOSP 开源组件*——Android 框架 API（含 `android.speech.tts` 系统 TTS 框架）、AndroidX/Jetpack（Room、Compose、Media3、DataStore 等）。这些是随系统或随 APK 打包的本地开源代码，运行时不需要 Google 服务、不发起任何网络请求。若评审认为需进一步收紧（如剔除所有 Google 署名代码），需在架构评审时单独提出。

### 1.3 竞品简析

| 产品 | 优点 | 与本产品差距 |
|------|------|--------------|
| 阅读（Legado，开源） | 开源无广告、功能强 | 核心是"书源订阅"（在线爬取），本地文件管理是附属能力；界面与学习成本高；听书进度不与阅读进度同步 |
| 静读天下 Moon+ Reader | 本地阅读体验成熟 | 免费版有广告；听书依赖系统 TTS 但进度不同步；闭源 |
| 掌阅 / QQ阅读 / 起点 | 内容生态 | 在线书城为主，广告多，本地导入受限甚至被弱化 |
| 厚墨 等小众阅读器 | 曾经简洁好用 | 已停更/下架，无法维护 |
| 系统自带文件管理器 | 无 | 只能打开不能管理，无进度、无听书 |

**结论**：「本地文件管理 + 无广告 + 全离线 + 听读进度同步」的组合在市场中是明确空缺，即本产品定位。

### 1.4 产品目标

1. 扫描并管理本机 TXT / EPUB 小说文件，形成个人书架（增、删、改、查）
2. 提供干净现代的阅读体验，自动保存阅读进度
3. 提供完全离线的 TTS 听书，支持外放与耳机，**听书进度与阅读进度为同一条进度、双向同步**
4. 全程无广告、无网络依赖、无 Google 服务依赖

### 1.5 成功指标

- 飞行模式下完成「扫描导入 → 阅读 → 听书 → 退出 → 恢复进度」全流程无阻断
- 10MB GBK 编码 TXT 扫描导入 < 5s，章节识别准确率 > 99%（内置测试集）
- 听书 10 分钟后退出，重新打开书籍，阅读器定位偏差 ≤ 1 句
- 1 万本书架滚动流畅（P95 帧耗时 < 16ms）

## 2. 目标用户与使用场景

### 2.1 目标用户

- **本地藏书党**：手头有数百至数万本 TXT/EPUB，需要管理与阅读工具
- **通勤听书用户**：地铁/驾车/家务时听书，碎片时间切换回阅读
- **去 Google 化设备用户**：LineageOS / /e/OS / 国产无 GMS ROM 用户，需要不依赖 Google 的完整体验
- **隐私敏感用户**：拒绝账号注册、拒绝数据上传

### 2.2 核心场景

**场景 A：导入藏书**
用户把 `novels/` 文件夹（含 3000 本 TXT，GBK 与 UTF-8 混杂）拷入手机 → 打开 App → 添加扫描文件夹 → 自动识别编码、解析章节、生成书架，编码识别失败时可手动指定。

**场景 B：读到听，听到读**
晚上躺床上看《XXX》看到第 45 章第 3 页 → 困了，点"听书"→ 从当前页首开始朗读 → 定时 30 分钟后自动停止。第二天通勤路上继续听 → 到公司后打开阅读器，光标直接落在昨晚听到的句子处，接着看。

**场景 C：耳机与外放切换**
家中用外放听书 → 出门插上耳机自动切换并继续播放；拔掉耳机自动暂停，不会外放扰民。也可以在听书面板里手动强制"扬声器"或指定某个蓝牙耳机。

**场景 D：整理书架**
长按多选 → 批量打标签"玄幻"→ 删除已弃坑的书（可选同时删除源文件）→ 修改某本书被错误识别的书名与作者。

## 4. 功能详细需求

### F-01 书库扫描与导入

**用户故事**：作为本地藏书党，我希望指定文件夹后 App 自动找出所有小说并入库，不需要逐个手动添加。

**需求明细**：

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-01-01 | 通过系统文件选择器（SAF，`ACTION_OPEN_DOCUMENT_TREE`）添加一个或多个扫描文件夹，持久化访问授权 | P0 |
| F-01-02 | 递归扫描文件夹，识别 `.txt` / `.epub` 文件（扩展名不区分大小写） | P0 |
| F-01-03 | TXT 编码自动探测：UTF-8（含 BOM）→ GBK/GB18030 → Big5 回退链；乱码时支持逐书手动指定编码重新解析 | P0 |
| F-01-04 | TXT 章节自动解析：识别「第X章/回/节/卷」「Chapter N」「数字+标题」等格式，生成章节索引；识别失败时全书作为单章并提示 | P0 |
| F-01-05 | EPUB 元数据读取：书名、作者、封面、简介（解析 OPF）；封面提取到本地缓存 | P0 |
| F-01-06 | 扫描结果报告：新增 N 本 / 更新 N 本 / 无变化 N 本 / 失败 N 本（含原因列表） | P0 |
| F-01-07 | 增量更新：文件 mtime/size 变化时重建章节索引，**尽量保留阅读进度**（按章节序号对齐；对不齐时回退到第 1 章并提示） | P0 |
| F-01-08 | 去重：以文件 URI 为唯一键；同文件重复扫描不产生重复书籍 | P0 |
| F-01-09 | 单文件导入：SAF 文件选择器多选导入；支持第三方 App「分享/打开方式」接收 TXT/EPUB | P0 |
| F-01-10 | 大文件处理：10MB+ TXT 不整本读入内存，按章节字节偏移建立索引、按需加载 | P0 |
| F-01-11 | 扫描可取消；后台扫描时通知栏显示进度 | P1 |

**验收标准**：
- AC-F01-a：混合编码（UTF-8/GBK/Big5 各 10 本）测试集导入后正文无乱码
- AC-F01-b：章节测试集（50 种常见标题格式）识别准确率 > 99%
- AC-F01-c：修改某 TXT 追加一章后重新扫描，进度保留且新章节出现

| 编号 | 需求 | 优先级 |
|------|------|--------|

### F-06 听书（TTS 播放）

**用户故事**：作为通勤用户，我希望不看屏幕也能控制播放，并且任何安卓手机上都能离线出声——包括没有 Google 服务的手机。

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-06-01 | 使用 Android 系统 TTS 框架（AOSP API）；列出设备已安装的 TTS 引擎供选择；**不依赖 Google TTS** | P0 |
| F-06-02 | 语速（0.5x–3.0x）与音调调节，设置按书记忆 | P0 |
| F-06-03 | 无可用 TTS 引擎 / 无中文语音时的引导页：说明原因，指引安装开源离线引擎（eSpeak NG / RHVoice，展示 F-Droid 名称与官网文字说明，不发起网络请求），并提示可导入内置引擎模型（见 F-14） | P0 |
| F-06-04 | 播放控制：播放/暂停、上一句/下一句、上一章/下一章、章内进度拖动 | P0 |
| F-06-05 | 通知栏媒体卡片 + 锁屏控制（MediaSession），耳机线控/蓝牙媒体按键可用 | P0 |
| F-06-06 | 前台服务保活：熄屏/切后台持续播放；被系统回收后重进可恢复到退出时句子 | P0 |
| F-06-07 | 听书面板：当前章节名、当前朗读句子、进度条、语速快捷调节 | P0 |
| F-06-08 | 定时停止：15/30/45/60 分钟 / 本章结束 | P1 |
| F-06-09 | 阅读器内听读同步模式：朗读时阅读器高亮当前句并自动翻页跟随 | P1 |
| F-06-10 | 内置 sherpa-onnx 离线引擎作为兜底（模型经 SAF 导入或随 ttsBundle 变体打包），无任何系统引擎时仍可用 | P1 |

**验收标准**：
- AC-F06-a：熄屏连续播放 30 分钟不中断（Doze 场景）
- AC-F06-b：来电时自动暂停，挂断后按设置恢复或保持暂停
- AC-F06-c：无 GMS 模拟器 + 安装 eSpeak NG 后中文可朗读

### F-07 阅读/听书统一进度同步（核心差异化功能）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-07-01 | 统一位置模型：进度 =（章节序号, 章内字符偏移），阅读与听书读写**同一条记录**，不存在两条进度 | P0 |
| F-07-02 | 听 → 读：停止听书后打开阅读器，定位到最后朗读句子的开头 | P0 |
| F-07-03 | 读 → 听：从阅读器发起听书，从当前页第一个字符所在句开始朗读 | P0 |
| F-07-04 | 听书中每句结束更新进度（节流写入）；进度来源标记（read/listen）仅用于展示，不产生分叉 | P0 |
| F-07-05 | 进度百分比 =（当前章之前总字数 + 章内偏移）/ 全书字数 | P0 |

**验收标准**：
- AC-F07-a：听书 10 分钟 → 退出 → 打开阅读器，定位偏差 ≤ 1 句
- AC-F07-b：阅读到 45.3% → 开始听书 → 首句朗读者即该页首句

### F-08 音频输出选择（外放 / 耳机）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-08-01 | 默认跟随系统路由（插耳机走耳机，连蓝牙走蓝牙） | P0 |
| F-08-02 | 听书面板内输出设备选择器：扬声器 / 有线耳机 / 已连接蓝牙设备（枚举当前可用输出） | P0 |
| F-08-03 | 「强制扬声器」：插着耳机也可切回外放 | P0 |
| F-08-04 | 拔出耳机/断开蓝牙自动暂停（becoming noisy），避免公放 | P0 |
| F-08-05 | 音频焦点管理：来电/闹钟抢占时暂停（或降音量，可设置），结束后按设置恢复 | P0 |

**验收标准**：
- AC-F08-a：插有线耳机时切到「扬声器」，声音从外放发出

## 5. 非功能需求

| 类别 | 需求 |
|------|------|
| **离线合规** | ① offline 构建变体 AndroidManifest 不含 `INTERNET` 权限；② 依赖树不含 GMS/Firebase（CI 校验任务强制）；③ 飞行模式全流程验收通过 |
| **性能** | 书架 1 万本流畅；10MB TXT 首章打开 < 2s；章节跳转 < 300ms；TTS 起播 < 1.5s |
| **兼容性** | minSdk 26（Android 8.0）~ targetSdk 35；适配无 GMS 设备（LineageOS、/e/OS、国产 ROM）；平板横屏可用 |
| **隐私** | 零数据收集、零账号、零网络请求（offline 变体）；崩溃日志仅存本地 |
| **可靠性** | 听书前台服务防 Doze 杀死；进度写入失败可恢复（WAL + 写失败重试）；数据库版本迁移有测试 |
| **存储** | 进度/索引数据 < 1MB/万本；TTS 音频缓存 LRU ≤ 200MB，可清理 |
| **可维护性** | Kotlin 100%；分层清晰（见架构文档）；核心解析/分页/进度映射逻辑有单元测试覆盖 |
| **许可证合规** | 所有依赖许可证清单入关于页（Apache-2.0 / MIT / MPL-1.1 等，无 GPL 传染性风险项单独评审） |

## 7. 边界（明确不做）

3. ❌ 广告、推广、应用内支付 SDK（捐赠仅以静态二维码图片形式出现于关于页，不经任何支付 SDK）
4. ❌ 社交、评论、社区功能
5. ❌ 任何形式的联网统计/埋点/崩溃上报（崩溃日志仅本地）

## 附录 A：术语

| 术语 | 含义 |
|------|------|
| SAF | Storage Access Framework，安卓存储访问框架（无需存储权限即可访问用户授权目录） |
| GMS | Google Mobile Services（Google Play 服务框架），本产品不依赖 |
| TTS | Text-To-Speech，文本转语音 |
| 统一进度 | 阅读与听书共享的同一条（章节, 字符偏移）位置记录 |
| offline 变体 | 默认构建变体，不声明 INTERNET 权限 |
| full 变体 | 可选构建变体，含 WebDAV 备份（V2），声明 INTERNET，仍不含任何 Google 服务 |

## 附录 B：参考项目 novelmgt 的取舍

| novelmgt 能力 | 本 Android 版决策 |
|---------------|-------------------|
| 书架/标签/统计/导入导出 | 保留（统计降级为书架顶部简单计数，V2 再评估完整统计页） |
| TXT 多编码探测、章节正则解析、中文数字转换 | **移植**（Dart → Kotlin） |
| EPUB/MOBI/PDF 导入 | V1 仅 EPUB；PDF/MOBI V2 评估 |
| 繁简切换（OpenCC） | V2 移植 |

| 爬虫抓取（crawler_service/book_source） | **明确不做** |
| NAS 服务端书库 / Web 端 | 不做 |
